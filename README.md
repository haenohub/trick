# 리프테일 · LeafTale

숲에서 시작해 바다로 이어지는 쿼터뷰 도트 판타지 RPG. 지역 2까지 플레이할 수 있습니다.

**플레이:** https://haenohub.github.io/trick/

**8방향 아틀리에:** https://haenohub.github.io/trick/directions.html

## 준비된 콘텐츠

- 햇살잎 숲 / 은물결 해안림, 마을 2곳과 전투 맵 8곳.
- 각 맵의 외곽·보행 면적을 기존의 5~10배로 확장. 밭둑길·세로 샛길·지그재그 강변·고리길·순환 숲길·섬 연결 습지 등 서로 다른 동선.
- 월드를 기존의 70% 배율로 표시하며 캐릭터를 부드럽게 따라가는 카메라와 비율을 보존하는 미니맵. NPC는 서비스 건물 앞에, 몬스터는 종별 서식 구역에 배치.
- 수림창사·별잎술사·숲그늘궁수·약초술사와 8개 2차 전직 (레벨 25, 조개등 마을).
- 개별 설명·능력치·독립 드롭 확률을 가진 몬스터 40종, 지역 보스 2종.
- 장비·약초·재료·소비품 42종과 몬스터별 고유 전리품 40종, 총 82종의 아이템과 각 아이템의 이야기.
- 수동 전투, 공격 예고, 4개 직업 기술 슬롯, 장비, 도감, 퀘스트 13개.
- 약초 채집, 제작, 연금술, 장비 분해, 접속하지 않아도 시들지 않는 개인 화단.
- 브라우저 자동 저장, JSON 저장 내보내기·가져오기, 모바일 터치 조작.
- 별도 Node.js 서버를 통한 실시간 이동·몬스터·전투·채팅·게스트 저장.

현재 GitHub Pages 공개판은 브라우저 저장 모험으로 시작합니다. 실제 인터넷 멀티플레이에는 별도 서버 호스팅이 필요합니다. Pages는 WebSocket 서버나 데이터베이스를 실행하지 않습니다. 서버 코드는 포함되어 있으며, 로컬에서 두 클라이언트/두 브라우저 접속을 검증했습니다.

## 개발과 실행

Node.js 24:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm test
npm start
```

`npm start`는 HTTP와 WebSocket 서버를 8080 포트에서 실행합니다. `/health`로 상태를 확인합니다. 브라우저의 설정 → 게임 서버 주소에 로컬 서버의 `/ws` 주소를 입력하면 온라인 모험으로 전환됩니다. 서버 모험은 기존 브라우저 모험과 분리됩니다.

정적 화면만 개발하려면 `npm run serve`를 사용할 수 있습니다. 코드를 바꾼 뒤 `npm run build`로 `dist`를 갱신합니다.

환경에 기본 npm 캐시 경로가 없다면 명령에 `--cache /workspace/.cache/leaftale-npm`을 추가하세요.

## 조작

| 입력                    | 동작                                     |
| ----------------------- | ---------------------------------------- |
| 바닥 클릭 / 터치        | 장애물을 우회해 목적지로 이동            |
| 바닥 클릭               | 장애물을 우회하여 이동                   |
| 몬스터 클릭 / Space / J | 기본 공격                                |
| 1 / 2 / 3 / 4           | 직업 스킬 (1 / 4 / 8레벨 / 전직 때 해금) |
| E                       | 대화, 약초 잎 따기, 다음 맵 이동         |
| Shift + E               | 약초 포기 수확                           |
| Q                       | 보들잎 연고                              |
| Tab                     | 가까운 적 선택                           |
| I / B / M / C           | 가방 / 제작 / 지도 / 직업                |
| L / K / H               | 이야기 / 도감 / 도움말                   |
| Esc                     | 창 닫기                                  |

첫 마을 동쪽 길 끝의 빛나는 표식을 클릭하거나 가까이에서 E를 눌러 새싹 울타리로 갑니다. 이야기 진행도를 채운 뒤 보상을 받아 다음 이야기를 엽니다. 그루터기 할아범을 진정시키면 해안으로 갈 수 있습니다.

## 검증

`npm test`는 콘텐츠 무결성, 모든 몬스터의 드롭 확률, 전투 보상, 제작의 원자성, 전직 8종, 회피, 저장 복원, 두 WebSocket 클라이언트의 동기화·채팅·서버 재시작 복원을 검증합니다.

Playwright Python과 Chromium이 준비된 환경에서는 정적 서버를 띄운 뒤:

```sh
python3 scripts/browser-smoke.py http://127.0.0.1:8080/
```

이 검사는 격리된 브라우저 프로필에서 실제 UI로 네 직업 전투·여덟 전직·제작·화단·도감·저장·모바일 화면을 확인합니다. 사용자의 저장 데이터는 건드리지 않습니다.

## 이미지 생성 아트

지역 1·2의 맵 10장, 직업 4종, 몬스터 40종, NPC 8명, 장비·스킬 아이콘, 효과·인터페이스 장식을 실제 이미지 생성 도구로 제작해 적용했습니다. 몬스터는 실제 프레임 32×32·48×48·64×64, 플레이어/NPC는 48×48, 아이템은 16×16, 효과는 32×32·48×48·64×64로 패킹했으며 영상 참조로 추출한 최대 256색 공통 팔레트와 공통 기본 픽셀 배율을 사용합니다. 마우스 바닥 클릭/터치 이동을 사용합니다.

플레이어 4종·NPC 8명·몬스터 40종은 입체 구조를 기준으로 각각 8방향을 새로 그렸습니다. 52개의 8×8 모션 시트와 416개의 단독 방향 PNG를 제공하며, 이동과 공격 방향에 따라 실제 게임에 적용합니다. 8방향 아틀리에는 검색·방향 전환·모션 재생·PNG 다운로드를 지원합니다. 방향별 생성 프롬프트는 `art/directional-sources.json`, 패커는 `scripts/pack-directions.mjs`입니다.

업로드 영상의 얇은 색 외곽선과 밝은 픽셀 음영을 기준으로 맵·배우·아이템·효과·타이틀까지 67개 원화를 전면 재생성했습니다. 검은 테두리를 덧칠하던 패커 처리를 제거하고, 월드 전체에서 같은 원본 픽셀 기준을 사용합니다. 현재 월드는 2배 기본 배율에 70% 줌을 함께 적용하고 도감·UI는 2배율을 유지합니다. 도감에도 새 이미지와 2배율 아이템 아이콘을 적용했습니다. 대형 맵용 지형 타일 10종과 건물·다리 소품 16종을 추가로 이미지 생성했으며, 원본 프롬프트는 `art/world-sources.json`, 패커는 `scripts/pack-world.mjs`입니다. 현재 스타일 프롬프트는 `art/refinement-sources.json`, 색상표는 `art/shared-palette.json`, 전후 외곽선 측정은 `art/style-audit.json`에 있습니다.

실제 확인한 시트 배열은 `site/assets/manifest.json`, 생성 프롬프트는 `art/pixel-sources.json`, 네이티브 파일 536개의 원본 연결과 체크섬은 `art/generated-assets.json`에 있습니다. 아트 구성과 애니메이션 보정의 현재 범위는 [ART_REWORK.md](ART_REWORK.md)를 참고하세요. `npm run art:requests`는 요청 명세만 갱신합니다.

## 파일 구조

독립 HTML 몬스터 도감은 [`site/bestiary.html`](site/bestiary.html)입니다. 40종의 서사·서식지·능력치·확정 보상·드롭 확률/수량과 아이템 설명을 검색하고 지역·사냥터·분류로 필터링할 수 있습니다. HTML 저장 및 필터 결과 전체 인쇄를 지원합니다. 다운로드한 파일의 텍스트 데이터는 오프라인으로 열리며, 이미지는 공개 에셋을 불러옵니다. `npm run build` 때 게임 데이터에서 자동으로 다시 생성됩니다. 화면 수정은 `templates/bestiary.html`, 데이터 연결은 `scripts/build-bestiary.mjs`에서 합니다.

- `site/data.js`: 맵·직업·몬스터·아이템·퀘스트 데이터.
- `site/world-layout.js`: 맵별 지형·충돌·출입구·서식 구역·건물 배치의 공유 기준.
- `site/core.js`: 브라우저와 서버가 공유하는 전투/성장/경제 판정.
- `site/renderer.js`: 쿼터뷰 렌더링과 스프라이트 애니메이션.
- `site/app.js`: 입력·메뉴·로컬 저장·네트워크 연결.
- `server/index.mjs`: 서버 권한 판정, 실시간 연결, 세션 저장.
- `scripts/`: 아트 생성·빌드·배포 검증·브라우저 검증.
- `tests/`: 콘텐츠·게임 규칙·온라인 서버 검증.

배포는 [DEPLOYMENT.md](DEPLOYMENT.md), 서버 운영은 [server/README.md](server/README.md)를 참고하세요.
