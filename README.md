- 승인한 기본 모습과 576개 방향 이미지는 유지하고, 플레이어 4종과 몬스터 60종에 이미지 생성으로 추가한 중간 자세를 끼워 넣었습니다. 방향별 시트는 8→16칸, 걷기는 4→8프레임이며 공격 준비 3프레임·타격 2프레임·회복 2프레임을 구분합니다. 아틀리에에서 준비/명중/회복과 전체 연계를 재생할 수 있습니다.
- 플레이어의 기본 공격과 공격 스킬은 준비 후 두 번째 타격 프레임에서 피해·효과음·타격 흔들림을 발생시킵니다. 몬스터도 예고→타격→회복을 같은 서버 시계로 처리합니다. 준비 중 이동·맵 변경이나 대상의 사거리 이탈은 늦은 피해를 막습니다. 회피 이동은 즉시 사용할 수 있습니다.
- 이펙트는 9종의 16프레임 원본으로 재생성했습니다. 포탈과 바닥 클릭 표시를 분리하고, 프레임의 고정 원점과 투명 여백을 지켜 옆 프레임이 침범하지 않게 패킹합니다. 획득 입자는 아이콘 뒤에서 재생하며 실제 아이템은 앞에 표시합니다.
- 8개 전투 맵에 서로 다른 갈림길·합류 지점·순환길·넓은 터를 추가했습니다. 보물함은 두 번 굽는 5칸 샛길 안쪽에서 발견합니다. 각 맵의 약초는 물가·그늘·낙엽·소금밭 등 이름 있는 3개 군락의 12개 채집 지점에 자랍니다. 지도에서 군락과 혼합 서식종을 확인합니다.
- 일반 몬스터는 여러 구역에 나뉘어 출현하며 다른 종과 서식 공간을 공유합니다. 환경이 맞는 인접 맵에는 같은 일반종이 소수 출현합니다. 보스는 고유 전투 터를 지키고 마을은 안전합니다. 게임 도감과 HTML 도감의 서식지·아이템 획득처도 실제 배치를 표시합니다.
- 신규 원본과 요청은 `art/motion-sources.json`, 기존 모습 비교 자료는 `art/motion-baseline.json`에 기록합니다. 추가 생성 원본과 `art/motion-baseline.json`의 기준 커밋이 있는 환경에서 `node scripts/apply-motion-art.mjs`로 패킹하고 `npm run build`로 도감을 갱신합니다. 세이브의 진행과 개봉·발견 기록은 유지하며 기존 위치가 여전히 걸을 수 있는 곳이면 그대로 이어집니다.

## v0.11.0 화면·조작·리프테일 도감

- 첫 화면은 소개와 캐릭터 선택을 나누어 배치하고 화면 높이에 따라 간격과 장식 문단을 조정해 스크롤 없이 시작할 수 있습니다.
- 기본 스킬 키는 **Q/W/E/R**, 가까운 바닥 전리품 하나 줍기는 **A**입니다. A를 누를 때마다 가까운 소유 전리품 하나가 기존 회전 비행 연출로 획득됩니다. 상호작용·약초 채집은 **F**(포기 수확 Shift+F), 연고 사용은 **T**로 옮겼습니다.
- I/C/B/M/L/K/H/O로 인벤토리·스킬·제작·지도·이야기·도감·도움말·설정을 열고 같은 키로 닫습니다. **P**는 키보드 모양 단축키 창입니다. 사용 중인 키를 골라 변경할 수 있으며 중복·고정 키를 검사하고 이 브라우저에 저장합니다.
- 인벤토리는 한 줄 5칸의 아이콘으로 표시합니다. 마우스 올리기·키보드 초점·터치로 설명과 사용/장착/분해/판매 버튼을 확인합니다.
- 게임 안과 독립 HTML 문서의 이름을 **리프테일 도감**으로 통일했습니다. 몬스터60종에 아이템102종의 서사·능력치·사용 직업·제작법·획득처·드롭 확률을 더하고, 독립 도감도 글꼴을2pt 키웠습니다. 아이템 검색·분류·인쇄·HTML 내보내기·오프라인 텍스트 보기를 지원합니다.

## v0.10.0 전투·탐험 개선

- 창사는 방어 흡수로 반격을 충전해 관통 찌르기에 사용하고, 휩쓸기로 일반 적의 공격 준비를 끊습니다. 술사는 달씨앗을 모아 광역 폭발을 강화합니다. 궁수는 짧은 회피 무적과 회피 후 한 발 강화를, 약초술사는 독 3겹과 머무는 아군을 회복하는 정원을 사용합니다. 직업 창(C)에서 연계 설명을 확인합니다.
- 몬스터는 장애물을 우회해 추적하며 벽 너머로 공격하지 않습니다. 원거리 적은 거리를 벌리고, 서식지를 멀리 벗어나면 귀환해 회복합니다. 일반 무리는 종당 6마리로 조정해 진입 동선의 밀집도를 낮췄습니다.
- 그루터기 수호자와 푸른숨 해룡은 체력에 따라 3단계로 변하며 서로 다른 뿌리 교차·수관 파문·물대포·해일·물기둥 패턴을 사용합니다. 준비 시간·위험 경계·고리 안의 안전 구역·공격 후 빈틈을 표시합니다.
- 기존 스프라이트 이펙트와 짧은 화면 흔들림으로 타격을 보강했습니다. 직업별 타격·방어·회피·보스 경고·보물 발견 효과음은 직접 합성하며 상단 음표 버튼으로 켭니다. 모션 줄이기 설정에서는 화면이 흔들리지 않습니다.
- 전투 맵 8곳마다 연결된 짧은 샛길과 보물함을 추가했습니다. 마을의 기록을 포함한 발견 장소 18곳에 고유 설명과 1회 경험치 보상이 있습니다. 지도(M)에서 발견 기록을 읽고 미니맵에서 조사한 장소와 보물함을 확인합니다.
- 보물함은 클릭 또는 가까이에서 E로 열고, 바닥에 떨어진 보물을 클릭해 획득합니다. 지역 보스 맵의 상자는 해당 수호자를 진정시켜야 열립니다. 개봉·발견·미수령 보상을 함께 저장해 재접속으로 내용물이 사라지거나 중복되지 않습니다.
- 새 이미지 생성 없이 현재 에셋을 재사용합니다. 이전의 그래픽 교체 미완료 70개 요청은 그대로 남아 있습니다. 테스트 배율과 70% 게임창도 유지합니다.

## 준비된 콘텐츠

- 햇살잎 숲 / 은물결 해안림, 마을 2곳과 전투 맵 8곳.
- 각 맵의 외곽·보행 면적을 기존의 5~10배로 확장. 밭둑길·세로 샛길·지그재그 강변·고리길·순환 숲길·섬 연결 습지 등 서로 다른 동선.
- 월드는 원래의 도트 배율로 표시하며 캐릭터를 부드럽게 따라가는 카메라와 비율을 보존하는 미니맵. NPC는 서비스 건물 앞에, 몬스터는 종별 서식 구역에 배치.
- 수림창사·별잎술사·숲그늘궁수·약초술사와 8개 2차 전직 (레벨 25, 조개등 마을).
- 개별 설명·능력치·독립 드롭 확률을 가진 몬스터 60종, 지역 보스 2종.
- 장비·약초·재료·소비품 42종과 몬스터별 고유 전리품 60종, 총 102종의 아이템과 각 아이템의 이야기.
- 수동 전투, 공격 예고, 4개 직업 기술 슬롯, 장비, 도감, 퀘스트 13개.
- 약초 채집, 제작, 연금술, 장비 분해, 접속하지 않아도 시들지 않는 개인 화단.
- 브라우저 자동 저장, JSON 저장 내보내기·가져오기, 모바일 터치 조작.
- 별도 Node.js 서버를 통한 실시간 이동·몬스터·전투·채팅·게스트 저장.

현재 GitHub Pages 공개판은 브라우저 저장 모험으로 시작합니다. 실제 인터넷 멀티플레이에는 별도 서버 호스팅이 필요합니다. Pages는 WebSocket 서버나 데이터베이스를 실행하지 않습니다. 서버 코드는 포함되어 있으며, 로컬에서 두 클라이언트/두 브라우저 접속을 검증했습니다.

## 개발과 실행

Node.js 24:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm test
npm start
```

`npm start`는 HTTP와 WebSocket 서버를 8080 포트에서 실행합니다. `/health`로 상태를 확인합니다. 브라우저의 설정 → 게임 서버 주소에 로컬 서버의 `/ws` 주소를 입력하면 온라인 모험으로 전환됩니다. 서버 모험은 기존 브라우저 모험과 분리됩니다.

정적 화면만 개발하려면 `npm run serve`를 사용할 수 있습니다. 코드를 바꾼 뒤 `npm run build`로 `dist`를 갱신합니다.

환경에 기본 npm 캐시 경로가 없다면 명령에 `--cache /workspace/.cache/leaftale-npm`을 추가하세요.

## 이미지 생성 아트

지역 1·2의 맵 10장, 직업 4종, 몬스터 60종, NPC 8명, 장비·스킬 아이콘, 효과·인터페이스 장식을 실제 이미지 생성 도구로 제작해 적용했습니다. 몬스터는 실제 프레임 32×32·48×48·64×64, 플레이어/NPC는 48×48, 아이템은 16×16, 효과는 32×32·48×48·64×64로 패킹했으며 최대 256색 공통 팔레트와 공통 기본 픽셀 배율을 사용합니다. 마우스 바닥 클릭/터치 이동을 사용합니다.

플레이어 4종·NPC 8명·몬스터 60종은 입체 구조를 기준으로 각각 8방향을 새로 그렸습니다. 72개의 8×8 모션 시트와 576개의 단독 방향 PNG를 제공하며, 이동과 공격 방향에 따라 실제 게임에 적용합니다. 8방향 아틀리에는 검색·방향 전환·모션 재생·PNG 다운로드를 지원합니다. 방향별 생성 프롬프트는 `art/directional-sources.json`, 패커는 `scripts/pack-directions.mjs`입니다.

새 배우 20종은 첨부 게임 스크린샷에서 추출한 가벼운 색감·큰 명암 형태·얇은 국소색 경계를 사용합니다. 새 배우는 각 8방향을 새로 그린 원화에서 중립 통과 포즈를 재사용해 4프레임 보행 주기를 구성합니다. 숲 약초상 원화는 6행으로 생성되어 NPC 피격에는 공격 준비 포즈를 재사용합니다. 방향을 복제·반전하지 않습니다. 10종의 모서리 지형 시트는 맞닿는 가장자리 픽셀이 같도록 기술적으로 패킹합니다. 새 이미지 생성 원화·프롬프트와 미완료 70개 요청은 `art/storybook-sources.json`에 기록합니다. 맵·아이템·효과 등 기존 원화는 이전 스타일을 유지하며 공통 팔레트는 `art/shared-palette.json`에 있습니다.

실제 배포 배열은 `site/assets/manifest.json`, 네이티브 PNG 738개의 원본 연결과 체크섬은 `art/generated-assets.json`에 기록합니다. 런타임에서 102개 아틀라스를 읽습니다. 원화와 ImageMagick이 있는 환경에서는 `node scripts/apply-storybook.mjs`로 재패킹할 수 있습니다. 일반 빌드·배포는 커밋된 PNG만 사용합니다. 자세한 버전별 아트 기록은 [ART_REWORK.md](ART_REWORK.md)를 참고하세요.

## 파일 구조

독립 HTML 리프테일 도감은 [`site/bestiary.html`](site/bestiary.html)입니다. 몬스터60종과 아이템102종의 서사·서식지·능력치·제작법·획득처·드롭 확률/수량을 검색하고 지역·사냥터·분류로 필터링할 수 있습니다. HTML 저장 및 필터 결과 전체 인쇄를 지원합니다. 다운로드한 파일의 텍스트 데이터는 오프라인으로 열리며, 이미지는 공개 에셋을 불러옵니다. `npm run build` 때 게임 데이터에서 자동으로 다시 생성됩니다. 화면 수정은 `templates/bestiary.html`, 데이터 연결은 `scripts/build-bestiary.mjs`에서 합니다.

- `site/data.js`: 맵·직업·몬스터·아이템·퀘스트 데이터.
- `site/world-layout.js`: 맵별 지형·충돌·출입구·서식 구역·건물 배치의 공유 기준.
- `site/core.js`: 브라우저와 서버가 공유하는 전투/성장/경제 판정.
- `site/combat.js`: 공격 범위·보스 패턴·직업 연계 설명.
- `site/exploration.js`: 발견 장소·보물함·고유 설명과 보상.
- `site/audio.js`: 직업·전투·탐험 효과음 합성.
- `site/controls.js`: 기본 단축키·물리 키 입력·저장 검증과 중복 검사.
- `site/renderer.js`: 쿼터뷰 렌더링과 스프라이트 애니메이션.
- `site/app.js`: 입력·메뉴·로컬 저장·네트워크 연결.
- `server/index.mjs`: 서버 권한 판정, 실시간 연결, 세션 저장.
- `scripts/`: 아트 생성·빌드·배포 검증·브라우저 검증.
- `tests/`: 콘텐츠·게임 규칙·온라인 서버 검증.
